# SUTRA GCS Operator Guide

## Operations Overview
1. **Live Ops / Connection**: Discover or manually connect to PX4/ArduPilot SITL or hardware.
2. **Dashboard GIS**: Draw geofences, monitor live telemetry vectors, view 3D terrain elevation.
3. **Mission Planning**: Create waypoints, optimize routes, run preflight checks, upload to flight controller.
4. **AI Ops**: View real-time recommendations, threat alerts, battery/comms failure predictions, and use the natural language prompt assistant.
5. **Fleet Swarm**: Select formations (V-Formation, Grid, Diamond), monitor inter-drone separation, and view task allocations.
6. **Operations Center**: Audit operator actions, monitor FPS/memory/network metrics, and verify production feature flags.
