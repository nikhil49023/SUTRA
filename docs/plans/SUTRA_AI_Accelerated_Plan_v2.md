## 5. Verification & Safety Guardrails

To ensure AI-generated code works flawlessly:

1. **Rule 1 — Never Deploy Without Gazebo SITL**: All AI-generated nodes must run in Gazebo Sim first.
2. **Rule 2 — Modular ROS 2 Topics**: Keep interface messages standardized (`geometry_msgs/msg/Twist`, `nav_msgs/msg/Odometry`, `sensor_msgs/msg/Image`).
3. **Rule 3 — Empirical Log Verification**: Every test must print explicit logs showing 0 syntax/runtime crashes before merging.
