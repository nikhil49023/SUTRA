2. Edge AI Detection (Subsystem C): YOLOv8-Nano TensorRT processes frame (<5ms) ➔ Bounding box extracted ➔

5. Distributed Consensus (Subsystem B): SwarmRAFT leader logs survivor location into replicated swarm state machine ➔

6 Minimum Viable Defense (MVD) — Top 7 Jury Trap Questions

Every teammate must be able to answer these core technical questions from first principles:

Q1: "Why use ORCA 3D instead of simple Artificial Potential Fields (APF)?"

Answer: APF suffers from local minima traps and oscillation. ORCA computes collision-free velocity obstacles geometrically with mathematical reciprocity guarantees, preventing deadlock among 5+ drones.

Q2: "What happens when 2 drones lose Wi-Fi mesh connectivity?"

Answer: SwarmRAFT consensus uses distributed heartbeat timers. Sub-swarms without quorum (N/2 + 1) transition to autonomous localized search and failsafe to last rendezvous waypoints.

Q3: "How do you calculate accurate GPS lat/long from a 2D bounding box?"

Answer: Using pinhole camera inverse projection with drone attitude quaternions (roll/pitch/yaw from VIO) to project an optical ray onto DEM terrain, converting intersection to WGS84 GPS.

Q4: "Why use Flask + Leaflet instead of heavy COTS software like QGroundControl?"

Answer: SUTRA GCS is a custom tactical multi-UAV dashboard providing real-time multi-agent swarm overlays, automated search polygon partitioning, and zero-install browser accessibility for NDMA field teams.

Q5: "How do you ensure safety under hardware or communication failure?"

Answer: Tiered failsafes: Layer 1 is 1-click Emergency RTL over WebSocket; Layer 2 is onboard PX4 geofence/battery auto-land; Layer 3 is NDMA physical exclusion zones.

Q6: "How do you prove your system achieves <5ms perception and <100ms failover?"

Answer: Strict empirical verification suites capturing live pytest --durations stdout, ROS 2 topic hz logs, and TensorRT profiling logs rather than synthetic estimates.

Q7: "Did you generate all this code with an AI LLM during prep?"

Answer: AI served as an interactive research assistant for documentation review. The architecture, mathematical modeling, test suites, and integration nodes are deeply understood, implemented, and defended from first principles.
